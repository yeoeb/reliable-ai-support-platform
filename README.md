## Local Development

Create and activate a virtual environment:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1

Install development dependencies:
python -m pip install -r requirements\dev.txt

Start the FastAPI application:
python -m uvicorn app.main:app --reload

Open API documentation:
http://127.0.0.1:8000/docs

Testing

Run the automated tests:
python -m pytest -v

## Database Migrations

Database schema changes are managed with Alembic.

### Check migration history

```powershell
alembic history
Check current database revision
alembic current
Apply all pending migrations
alembic upgrade head
Generate a migration from ORM metadata changes
alembic revision --autogenerate -m "description"

Always review autogenerated migration files before committing or applying them.

Roll back one migration
alembic downgrade -1

### Create user

```http
POST /users

Request:

{
  "email": "alice@example.com",
  "display_name": "Alice"
}

Responses:

201 Created — user created successfully
409 Conflict — email already exists
422 Unprocessable Entity — request validation failed
503 Service Unavailable — persistence service is temporarily unavailable

Authentication and RBAC are not implemented yet.

POST /users is currently a bootstrap registration boundary. Clients may only provide email and display_name; server-owned fields such as id, is_active, timestamps, roles, and permissions cannot be set by the request.
