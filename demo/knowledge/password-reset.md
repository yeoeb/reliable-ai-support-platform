# Password reset

Use the self-service password reset flow from the sign-in page. The reset link
expires after 15 minutes and can be used only once.

If self-service reset is unavailable, verify the requester's identity using the
approved support procedure before initiating a reset. Never ask a user to send
their current or new password through email, chat, or a support ticket.

Escalate suspected account takeover or repeated unexpected reset messages to
the security queue immediately.
